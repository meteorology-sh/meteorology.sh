This markdown file was authored by a human. The purpose in this instruction is to communicate how structured writing takes place in this code repository.

## When to use this skill

Anytime text content is written to a component, this skill is enforced.

## Rules

- Always prefer the simple, short explanation with minimal jargon
- Never use language model artifacts like thesis-antithesis patterns, dialectical hedging, or rhetorical equivocation
- Never use any sentence structures that set up and then negate or expand beyond expectations
- Always use direct, affirmative language

## Examples

> In the 1940s, American research in aeronautics led investigators to study the physics of condensation in the cold, higher altitudes of the atmosphere. In discovering a methodology through which supercooled liquid water droplets could be coaxed together into precipitation, this research culminated in a technological advancement, cloud seeding, the technology of making rain. A cloud is seeded by various materials in the form of crystalline dust, which nucleate supercooled liquid water and precipitate from the sky. This code repository is a geospatial visualization platform that composes several real-time meteorological datasets to evaluate which cloud formations are optimal targets for seeding. A subsequent evaluation shows that this application's work product is data which agrees with both independent quantitative measurements inspired by literature, and the qualitative judgment of meteorologists running cloud seeding missions.
